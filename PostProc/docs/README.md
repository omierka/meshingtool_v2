# PostProc Utilities

These scripts take the meshes/results generated by the main pipeline and render diagnostic snapshots.

- `render_all_snapshots.py` walks a case folder, loads every exported VTU, and saves raster images for quick inspection.
- `render_filtered_snapshot.py` focuses on the final filtered mesh and produces a single high-quality frame suitable for reports.

Both scripts expect the same folder layout as `run_all_cases.sh` and can be invoked manually once a case has finished running.

1. Run `python3 render_all_snapshots.py --cases-root CASES` to regenerate all snapshots/trims and automatically create `CASES/cases.pdf`. The PDF is assembled via LaTeX (requires `pdflatex` in `PATH`) so the case header, monitor histogram table, and trimmed images share the same layout on every page. Add `--keep-temp` if you want the temporary LaTeX workspace preserved for debugging, and `--skip-render` if you prefer to reuse the existing PNGs without rerunning ParaView.
